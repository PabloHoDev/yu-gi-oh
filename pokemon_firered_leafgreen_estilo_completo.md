## 1. Identidade do jogo

**Pokémon FireRed e Pokémon LeafGreen** são RPGs japoneses (JRPGs) de aventura, exploração, coleção e batalhas por turnos.

Foram lançados para o **Game Boy Advance** em 2004 e são remakes de **Pokémon Red/Green/Blue**, reconstruindo a aventura da região de Kanto com a apresentação visual e as melhorias técnicas da terceira geração.

### Classificação geral

| Característica | Descrição |
|---|---|
| Gênero principal | RPG / JRPG |
| Subgêneros | Aventura, exploração, coleção, batalha por turnos |
| Estrutura | Mundo dividido em áreas conectadas |
| Perspectiva | Top-down / visão superior |
| Gráficos | 2D |
| Estilo artístico | Pixel art |
| Construção dos mapas | Tile-based |
| Personagens | Sprites 2D |
| Combate | Turn-based |
| Progressão | Níveis, experiência, evolução e habilidades |
| Coleção | Pokédex |
| Plataforma original | Game Boy Advance |
| Época estética | Era dos portáteis de 32 bits / início dos anos 2000 |
| Realismo | Baixo |
| Direção visual | Colorida, estilizada, cartunesca |
| Mundo | Fantasia com elementos naturais e urbanos |

A própria Pokémon Company classifica os jogos como **RPG** e informa que foram lançados originalmente para Game Boy Advance. Também destaca que os locais, Pokémon e animações foram melhorados em relação aos jogos originais.

Fonte oficial:

# 2. Definição visual em uma frase

Se fosse necessário definir o estilo visual de FireRed/LeafGreen em uma única frase:

> **RPG japonês 2D de pixel art, colorido e estilizado, com visão superior, mapas construídos com tiles, personagens representados por pequenos sprites e batalhas por turnos em telas dedicadas.**

Em termos mais técnicos:

> **2D top-down tile-based pixel-art JRPG with sprite-based characters, colorful environments, menu-driven turn-based battles and GBA-era visual design.**

---

# 3. Estilo gráfico

## 3.1 2D

O jogo é essencialmente **2D**.

Não existe um mundo tridimensional contínuo como em jogos modernos.

Os elementos são representados por:

- sprites;
- tiles;
- imagens 2D;
- efeitos 2D;
- animações quadro a quadro;
- elementos de interface;
- fundos desenhados.

A sensação de profundidade vem da composição dos elementos no mapa, e não de uma câmera 3D.

---

# 4. Pixel art

O estilo utiliza **pixel art**, característica muito importante da identidade visual.

Os elementos possuem:

- pixels claramente definidos;
- sprites pequenos;
- detalhes simplificados;
- contornos visuais fortes;
- áreas de cor relativamente sólidas;
- sombras simplificadas;
- paletas limitadas em comparação com jogos modernos;
- formas reconhecíveis mesmo em baixa resolução.

Entretanto, FireRed/LeafGreen não possuem o aspecto extremamente rudimentar dos primeiros Pokémon de Game Boy.

O Game Boy Advance permitiu uma apresentação:

- mais colorida;
- mais detalhada;
- com sprites maiores;
- com mapas mais ricos;
- com mais animações;
- com efeitos visuais mais elaborados.

---

# 5. Paleta de cores

A direção visual utiliza cores vivas e facilmente distinguíveis.

Predominam:

- verdes;
- azuis;
- vermelhos;
- amarelos;
- laranjas;
- marrons;
- cinzas;
- roxos;
- tons claros para menus e interiores.

A paleta contribui para uma estética:

**alegre + aventureira + cartunesca + nostálgica.**

Não existe uma tentativa de representar o mundo de forma fotográfica ou realista.

---

# 6. Perspectiva e câmera

A exploração utiliza principalmente uma perspectiva:

## Top-down / visão superior

O jogador observa o personagem de cima, com uma pequena inclinação visual.

Não é uma visão completamente vertical de um mapa técnico. É uma perspectiva estilizada típica dos RPGs 2D de consoles portáteis.

### Características

- câmera fixa;
- câmera seguindo o jogador;
- ausência de rotação livre;
- ausência de câmera 3D;
- movimentação em um mapa 2D;
- áreas delimitadas;
- transições entre mapas.

A câmera acompanha o personagem enquanto ele percorre cada área.

---

# 7. Construção dos mapas — Tile-based

Uma das características mais importantes do estilo é a construção dos ambientes utilizando **tiles**.

Em vez de desenhar cada mapa como uma única imagem gigante, o cenário é construído a partir de pequenas peças gráficas reutilizáveis.

Exemplo conceitual:

```text
🌳 🌳 🌳 🌳 🌳 🌳 🌳
🌳 🟩 🟩 🟩 🟩 🟩 🌳
🌳 🟩 🟩 🧍 🟩 🟩 🌳
🌳 🟩 🟩 🟩 🟩 🟩 🌳
🌳 🌳 🌳 🌳 🌳 🌳 🌳
```

Os símbolos acima são apenas uma representação conceitual.

No jogo real, essas áreas são compostas por pequenas peças de terreno.

### Tipos de tiles

- grama;
- caminhos;
- árvores;
- água;
- areia;
- pedras;
- flores;
- paredes;
- pisos;
- telhados;
- portas;
- cercas;
- pontes;
- obstáculos;
- elementos decorativos.

---

# 8. Estrutura do mundo

O mundo não é um único mapa aberto contínuo.

Ele é dividido em **áreas conectadas**.

Exemplo:

```text
[Cidade]
    ↓
[Rota]
    ↓
[Outra cidade]
    ↓
[Caverna]
    ↓
[Rota]
    ↓
[Nova cidade]
```

Essa estrutura permite que cada área tenha:

- identidade visual;
- música;
- layout;
- obstáculos;
- NPCs;
- Pokémon disponíveis;
- itens;
- desafios.

# 10. Personagens

Os personagens do mundo são representados por **sprites 2D pequenos**.

O protagonista possui sprites para diferentes direções.

### Direções

- cima;
- baixo;
- esquerda;
- direita.

A movimentação produz a sensação de um personagem pequeno caminhando sobre uma grade.

Os NPCs seguem o mesmo princípio.

---

# 11. Escala visual

O mundo é representado em uma escala estilizada.

O personagem é pequeno em relação aos ambientes.

Uma casa pode parecer grande o suficiente para comportar várias pessoas, enquanto o personagem ocupa apenas uma pequena quantidade de pixels na tela.

Essa diferença não procura representar proporções realistas.

Ela existe para:

- facilitar a leitura do mapa;
- permitir mapas maiores;
- manter o estilo cartunesco;
- tornar a navegação simples.

---

# 12. Sprites dos Pokémon

Os Pokémon recebem tratamento visual diferente durante as batalhas.

Eles aparecem como sprites maiores e mais detalhados.

A composição da batalha normalmente apresenta:

```text
        POKÉMON ADVERSÁRIO

              🐉

        ----------------

               VS

              🐢

          SEU POKÉMON
```

A representação acima é apenas conceitual.

Os sprites são desenhados em pixel art e possuem animações e efeitos associados às batalhas.

---

# 13. Sistema de batalha

O combate é baseado em **turnos**.

O jogador escolhe uma ação e o jogo executa as ações de acordo com as regras de batalha.

As principais opções são:

- **FIGHT**
- **BAG**
- **POKéMON**
- **RUN**

Ao selecionar **FIGHT**, o jogador escolhe um dos golpes disponíveis.

---

# 14. Interface de batalha

A interface utiliza caixas, menus, textos e barras de status.

Elementos típicos:

- nome do Pokémon;
- nível;
- HP;
- barra de HP;
- opções de combate;
- nome dos golpes;
- PP dos golpes;
- mensagens de batalha;
- indicadores de estado.

O design é simples e funcional.

A interface não ocupa toda a tela com elementos.

Ela deixa grande parte da área disponível para os sprites e o cenário da batalha.

# 24. Diferenças entre FireRed e LeafGreen

Os dois jogos compartilham essencialmente a mesma estrutura.

A principal função da divisão em duas versões é incentivar:

- troca de Pokémon;
- interação entre jogadores;
- coleção;
- obtenção de Pokémon exclusivos de cada versão.

### Identidade visual

FireRed utiliza uma identidade associada ao:

**vermelho / fogo / Charizard**

LeafGreen utiliza uma identidade associada ao:

**verde / natureza / Venusaur**

Isso não significa que os jogos tenham estilos gráficos completamente diferentes.

Visualmente, eles pertencem à mesma direção artística.

# 29. Direção artística

A direção artística pode ser descrita como:

> **Pixel art japonesa de RPG portátil, com forte uso de cores, formas simplificadas, sprites pequenos, cenários construídos em tiles e uma linguagem visual cartunesca.**

O objetivo visual não é impressionar pela quantidade de polígonos ou pela resolução.

O objetivo é:

**clareza + personalidade + legibilidade + variedade + charme.**

---

# 30. Como descrever os cenários

Uma descrição útil para reproduzir o estilo seria:

> Cenários 2D em pixel art, construídos por tiles modulares, vistos de cima, com paleta de cores vibrante e formas simplificadas. Árvores, grama, água, casas, caminhos e objetos possuem contornos claros e detalhes suficientes para serem identificados em baixa resolução. O ambiente possui estética cartunesca de RPG portátil do início dos anos 2000.

---

# 31. Como descrever os personagens

> Personagens pequenos representados por sprites de pixel art, com poucos pixels, silhuetas facilmente reconhecíveis, animações simples de caminhada e quatro direções principais. As proporções são estilizadas e não realistas.

---

# 32. Como descrever uma batalha

> Tela de batalha 2D com fundo simples, dois Pokémon representados por sprites pixelados em posições opostas, interface baseada em caixas de texto e menus, barras de HP, nível dos Pokémon, seleção de golpes e efeitos visuais 2D durante os ataques.

---

# 33. Como descrever o mapa

> Mapa 2D top-down construído com tiles repetíveis. O cenário combina terreno, obstáculos naturais, construções, caminhos, água, vegetação e objetos interativos. O jogador controla um pequeno sprite que percorre uma grade de movimentação enquanto a câmera acompanha sua posição.

---

# 34. Como descrever o estilo completo para um projeto

Se a intenção for utilizar FireRed/LeafGreen como **referência visual para criar outro jogo**, esta é uma descrição mais completa:

> **Estilo visual 2D de RPG portátil da era Game Boy Advance, baseado em pixel art tile-based e perspectiva top-down. O mundo é composto por mapas modulares construídos com pequenos tiles de terreno, vegetação, construções, água e objetos. Os personagens são pequenos sprites pixelados com animações simples de caminhada e quatro direções. A paleta é colorida e vibrante, com forte separação entre elementos do cenário. Os ambientes possuem aparência cartunesca e fantasiosa, sem realismo fotográfico. As batalhas utilizam telas 2D separadas, sprites maiores dos personagens/criaturas, interfaces em caixas, barras de status, menus e efeitos de ataque baseados em animações 2D. A interface é minimalista, legível e adaptada para uma tela pequena.**

# 37. Resumo final

**Pokémon FireRed e Pokémon LeafGreen são JRPGs 2D de exploração, coleção e batalhas por turnos, construídos especificamente para o Game Boy Advance.**

Visualmente, eles pertencem à linguagem dos RPGs portáteis de pixel art dos anos 2000:

**2D + pixel art + top-down + tile-based + sprites + cores vibrantes + mapas modulares + batalhas por turnos + interface simples.**

O aspecto mais característico é a combinação de:

```text
PIXEL ART
    +
VISÃO SUPERIOR
    +
MAPAS EM TILES
    +
SPRITES PEQUENOS
    +
CORES VIBRANTES
    +
EXPLORAÇÃO
    +
BATALHAS POR TURNOS
    +
COLEÇÃO
```

Essa combinação produz a identidade visual e de gameplay que associamos imediatamente a **Pokémon FireRed e LeafGreen**.
